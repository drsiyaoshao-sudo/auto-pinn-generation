# Dispatch Model Fine-Tuning

Fine-tunes Qwen2.5-0.5B to parse engineering language into structured JSON args
for the GaitSense local dispatch agents. Replaces the zero-shot 0.5B inference path
with a domain-adapted model that understands IMU terms, profile names, run IDs, and
engineering shorthand.

## Dataset

Generated by `generate_dispatch_pairs.py` using Claude Haiku to paraphrase seed examples.

| Task | Examples | Maps to |
|------|----------|---------|
| `plotter` | 400 | `{"profile": "flat\|stairs\|slope\|bad_wear", "mode": "healthy\|pathological"}` |
| `train_sum` | 320 | `{"run_id": "v21_2k\|v19\|...\|latest"}` |
| `uart_reader` | 320 | `{"log_path": "/tmp/gait_uart.log\|latest"}` |
| `model_compare` | 320 | `{"good_run_id": "v1\|...", "bad_run_id": "random\|v3\|..."}` |
| **Total** | **1,360** | Qwen2.5 chat JSONL, shuffled |

Output: `hybrid/training/data/dispatch_pairs.jsonl`

Regenerate at any time (adds more tasks or paraphrases):
```bash
python hybrid/training/generate_dispatch_pairs.py --n_paraphrases 20
python hybrid/training/generate_dispatch_pairs.py --tasks plotter --n_paraphrases 30
python hybrid/training/generate_dispatch_pairs.py --dry_run   # seeds only, no API
```

## Fine-Tuning

**Target model:** Qwen2.5-0.5B-Instruct
**Method:** LoRA (r=16, alpha=32), 4-bit quantised base
**Tool:** LLaMA-Factory (recommended) or Axolotl

### LLaMA-Factory (quickest path)

```bash
# Install
pip install llamafactory

# Register dataset
cp hybrid/training/data/dispatch_pairs.jsonl data/dispatch_pairs.jsonl
# Add to LLaMA-Factory dataset_info.json:
# "dispatch": {"file_name": "dispatch_pairs.jsonl", "formatting": "sharegpt"}

# Train
llamafactory-cli train \
  --model_name_or_path Qwen/Qwen2.5-0.5B-Instruct \
  --dataset dispatch \
  --template qwen \
  --finetuning_type lora \
  --lora_rank 16 \
  --lora_alpha 32 \
  --num_train_epochs 3 \
  --per_device_train_batch_size 8 \
  --learning_rate 2e-4 \
  --output_dir hybrid/training/checkpoints/dispatch_lora

# Merge + export GGUF
llamafactory-cli export \
  --model_name_or_path Qwen/Qwen2.5-0.5B-Instruct \
  --adapter_name_or_path hybrid/training/checkpoints/dispatch_lora \
  --export_dir hybrid/training/checkpoints/dispatch_merged \
  --export_quantization_bit 4

# Convert to GGUF for Ollama (requires llama.cpp)
python llama.cpp/convert_hf_to_gguf.py hybrid/training/checkpoints/dispatch_merged \
  --outtype q4_k_m \
  --outfile hybrid/training/checkpoints/dispatch_q4.gguf
```

### Deploy to Ollama

```bash
# Create Modelfile
cat > hybrid/training/Modelfile << 'EOF'
FROM hybrid/training/checkpoints/dispatch_q4.gguf
PARAMETER temperature 0.0
PARAMETER top_p 1.0
SYSTEM "You are a structured JSON extractor for engineering requests."
EOF

ollama create gaitsense-dispatch -f hybrid/training/Modelfile
ollama run gaitsense-dispatch "plot the flat profile"
```

### Switch dispatch agents to use the fine-tuned model

```bash
export OLLAMA_MODEL=gaitsense-dispatch
python hybrid/local_agents/run_plotter.py "plot stairs pathological"
```

The `LocalLLM` wrapper reads `OLLAMA_MODEL` from env — no code changes needed.
